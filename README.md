# NYC Public Schools SAT Analysis

**DataCamp Guided Project | Python | Pandas | Data Analysis**

## 🇺🇸 English Version

### Project Overview

This project analyzes SAT scores from public high schools in New York City using Python and Pandas.

The goal is to explore school performance in Mathematics, identify the top 10 schools based on their combined SAT scores, and investigate differences in score variability across NYC boroughs.

### Project Objectives

- Identify schools with an average Mathematics SAT score of 640 or higher.
- Rank the 10 schools with the highest combined SAT scores.
- Identify the borough with the largest standard deviation in combined SAT scores.

### Tools and Technologies

- Python
- Pandas
- Jupyter Notebook

### Dataset

The dataset contains information about New York City public schools, including boroughs and average SAT scores in Mathematics, Reading, and Writing.

The dataset was provided as part of the DataCamp guided project.

### Methodology

The analysis involved:

- Filtering schools based on Mathematics SAT scores.
- Creating a new column to calculate combined SAT scores.
- Sorting schools by their overall SAT performance.
- Grouping schools by borough.
- Applying statistical aggregations such as count, mean, and standard deviation.

### Key Findings

**1. Best Math Schools**

Identified 10 NYC public schools with an average Mathematics SAT score of 640 or higher.

**2. Top 10 Schools by Combined SAT Score**

The following schools achieved the highest combined SAT scores:

Este projeto analisa as pontuações do SAT de escolas públicas de ensino médio da cidade de Nova York, utilizando Python e Pandas.

O objetivo é explorar o desempenho das escolas em Matemática, identificar as 10 instituições com as maiores pontuações totais no SAT e investigar as diferenças na dispersão dessas pontuações entre os distritos de Nova York (*boroughs*).

### Objetivos do Projeto

- Identificar escolas com pontuação média igual ou superior a 640 em Matemática.
- Classificar as 10 escolas com as maiores pontuações totais no SAT.
