# NYC Public Schools SAT Analysis

## Project Overview

This project explores the SAT performance of public schools in New York City using Python and Pandas.

The analysis aims to identify schools with outstanding Mathematics scores, rank the top 10 schools based on their combined SAT scores, and investigate differences in SAT score variability across NYC boroughs.

## Project Objectives

- Identify schools with Mathematics scores equal to or above 80% of the maximum possible score (640 out of 800).
- Rank the 10 schools with the highest combined SAT scores.
- Identify the borough with the largest standard deviation in total SAT scores.

## Tools and Technologies

- Python
- Pandas
- Jupyter Notebook

## Dataset

The dataset contains information about New York City public schools, including boroughs and average SAT scores in Mathematics, Reading, and Writing.

## Methodology

The analysis involved:

- Filtering schools based on Mathematics scores.
- Creating a new column to calculate total SAT scores.
- Sorting schools by their combined SAT performance.
- Grouping schools by borough.
- Applying statistical aggregations such as count, mean, and standard deviation.

## Key Skills Demonstrated

- Data manipulation using Pandas.
- Data filtering and sorting.
- Creating calculated columns.
- Grouping and aggregation with `groupby()` and `agg()`.
- Descriptive statistical analysis.

# Análise do Desempenho no SAT das Escolas Públicas de Nova York

## Visão Geral do Projeto

Este projeto explora o desempenho das escolas públicas de Nova York no SAT, utilizando Python e Pandas.

A análise busca identificar escolas com excelentes resultados em Matemática, classificar as 10 escolas com as maiores pontuações totais no SAT e investigar as diferenças na variabilidade das pontuações entre os distritos de Nova York.

## Objetivos do Projeto

- Identificar escolas com pontuação em Matemática igual ou superior a 80% da pontuação máxima possível (640 de 800 pontos).
- Classificar as 10 escolas com as maiores pontuações totais no SAT.
- Identificar o distrito com o maior desvio-padrão nas pontuações totais do SAT.

## Ferramentas e Tecnologias

- Python
- Pandas
- Jupyter Notebook

## Conjunto de Dados

A base de dados contém informações sobre as escolas públicas de Nova York, incluindo seus distritos e as pontuações médias em Matemática, Leitura e Escrita.

## Metodologia

A análise envolveu:

- Filtragem de escolas com base nas pontuações de Matemática.
- Criação de uma nova coluna para calcular as pontuações totais do SAT.
- Ordenação das escolas de acordo com seu desempenho total.
- Agrupamento das escolas por distrito.
- Aplicação de agregações estatísticas, como contagem, média e desvio-padrão.

## Principais Habilidades Demonstradas

- Manipulação de dados com Pandas.
- Filtragem e ordenação de dados.
- Criação de colunas calculadas.
- Agrupamento e agregação com `groupby()` e `agg()`.
- Análise estatística descritiva.
